# Food Recipe App

A front-end SDC project developed using only HTML, CSS and JavaScript.

## Modules
- User Module: Signup, Login, Browse Recipes, Search/Filter, Recipe Details, Favourites
- Admin Module: Admin Login, Add Recipe, Edit Recipe, Delete Recipe

## Technologies
- HTML
- CSS
- JavaScript
- Local Storage
- CSS Grid and Flexbox
